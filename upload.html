New daily snapshot

Upload the CSV exactly as exported from the AGRISTACK portal. Pick the date the snapshot represents — the portal diffs this against the previous day to compute additions.

⚠ A snapshot for already exists. If you continue, that one will be replaced. The older version stays in GitHub commit history and can be restored from there if needed.

What happens next

  1. The CSV is saved as data/YYYY-MM-DD.csv and parsed.
  2. If GH_TOKEN + GH_REPO are set on Render, the file is committed to the GitHub repo and Render auto-redeploys.
  3. If a snapshot already exists for that date, it is replaced (overwrite) — old version stays in GitHub history.
  4. If "additions-only" is ticked, a sidecar .additive marker is saved next to the CSV so the dashboard SUMS it onto the previous cumulative instead of overlaying.
