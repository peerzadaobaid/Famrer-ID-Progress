How this works

  1. For each completed month (Aug, Sep, Oct 2026) upload the single CSV AGRISTACK gave you at that month-end. Each file contains only that month's new enrollments.
  2. The dashboard shows Total Issued = sum of all uploaded month baselines + current month's daily additions.
  3. Within the current month, use Upload daily as a routine — each day's CSV is cumulative-within-the-month.
  4. At month-end, come back here and click "Close current month" to freeze the latest daily snapshot into the next monthly baseline. Daily uploads for the following month then start clean.
