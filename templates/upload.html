What happens next

  1. The CSV is saved as data/YYYY-MM-DD.csv and parsed.
  2. If a GH_TOKEN + GH_REPO are configured on Render, the file is committed to the GitHub repo so Render redeploys automatically.
  3. Otherwise it stays on the current Render instance (ephemeral) — commit the file to the repo yourself to persist.
  4. The dashboard re-reads data/ on every page load and shows the latest state.
